# 06 — Question / Problem Statement Panel

## Purpose

Explain the task clearly enough that a beginner can attempt it without searching elsewhere.

## Content structure

1. Problem title
2. Difficulty and concept badges
3. Problem statement
4. Function signature
5. Input/parameter description
6. Return value description
7. Constraints
8. Visible examples with input and expected output
9. Optional notes and edge-case reminders

## Interaction

- Examples can be expanded/collapsed.
- Code examples use monospace formatting and a copy button if useful.
- “Copy example” must copy only the displayed example.
- Do not place hidden tests in this panel.
- If content is Markdown, render it with a safe Markdown renderer; do not use raw HTML injection.

## Components

- Card, Badge, Accordion, Tabs, Separator, Tooltip, Breadcrumb
- `lucide-react` icons for BookOpen, Copy, ChevronDown, Tag

## Acceptance checklist

- [ ] Title and difficulty are clear
- [ ] Function signature is readable
- [ ] Examples are copyable and correctly formatted
- [ ] Constraints are not hidden in tiny text
- [ ] No hidden test data is present
