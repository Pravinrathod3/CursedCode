# Frontend / Client AI Agent Rules

All frontend and UI development must strictly follow the cursedCode JJK theming rules:
See: [docs/rules.md](docs/rules.md)

Key non-negotiables:
1. Product name: `cursedCode`
2. Theme: Jujutsu Kaisen visual mood (dark, ink, glowing blue and violet, kanji watermarks, grade badges). Fan project.
3. Golden rule: Someone who has never heard of Jujutsu Kaisen must be able to use every screen with zero confusion. All labels use plain, standard words (Run, Visible tests, Hidden tests, Sandbox, Hint, Challenge, Progress). Do NOT theme standard vocabulary.
4. Hidden tests: show only test number and outcome (Passed, Wrong output, Runtime error, Timeout). NEVER render input, call, expected, output, or error text.
5. All design tokens, typography, and asset fallbacks must strictly follow `docs/rules.md`.
